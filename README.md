# Meesho Sales Dashboard | Power BI

## 📌 Project Overview
This project focuses on analyzing Meesho sales data using Power BI to identify sales trends, monitor key performance indicators (KPIs), and generate meaningful business insights.

## 🎯 Objectives
- Analyze overall sales and order performance.
- Track key business metrics using interactive visualizations.
- Identify sales trends and patterns.
- Support data-driven business decisions.

## 🛠️ Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Visualization

## 📊 Key KPIs
- Total Sales
- Total Orders
- Average Order Value
- Sales Trends

*Note: KPIs are included according to the metrics available in the dashboard.*

## 📈 Key Insights
The dashboard helps explore sales performance, order trends, and business patterns through visual reports and interactive filters.
